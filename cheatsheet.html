🗺️ 速查卡 Cheat Sheet ​

高频知识点的"一页纸"速查，面试前与 Code Review 时扫一眼。每条都链接回对应章节的完整讲解。

事件循环判定 ​

场景归属顺序
同步代码、console.log调用栈最先
Promise.then/finally、await 之后、queueMicrotask微任务当前轮全部清空
setTimeout/setInterval、I/O、UI 事件宏任务每轮只取一个

口诀：同步跑完 → 微任务清空 → 一个宏任务 → 循环。详见 1.5。

防抖 vs 节流 ​

防抖 debounce节流 throttle
行为停止触发 N ms 后执行一次每 N ms 最多执行一次
记忆等停止匀速跑
场景搜索联想、resize 完成滚动加载、按钮防连点

详见 1.8。

缓存决策 ​

带内容哈希的静态资源  → Cache-Control: max-age=31536000, immutable   (强缓存一年)
HTML / 入口文档       → Cache-Control: no-cache                       (每次协商)
实时数据(余额/库存)   → no-store
低频变化的数据        → 短 max-age + stale-while-revalidate

黄金法则:HTML 不强缓存,指纹资源强缓存。详见 6.2、SW 可编程层见 10.6。

竞态处理三招（优先级从高到低） ​

  1. 取消旧请求：AbortController（搜索、筛选必配）；
  2. 忽略过期结果：版本号/标志位比对；
  3. 防抖：减少触发频率（只能缓解，需与前两者组合）。

详见 6.5。

原理地基速查 ​

JS 执行管线（1.1）：源码 → 词法分析(token) → 语法分析(AST) → 字节码(Ignition/TurboFan) → 执行上下文创建（var→undefined、let/const→TDZ）→ 逐行执行。SyntaxError 解析期全段不执行，ReferenceError 执行期才抛。Babel/ESLint/SWC 都是 AST 改写。

首次渲染管线（10.1）：HTML→DOM 树 · CSS→CSSOM 树 → 渲染树（display:none 不入树、visibility:hidden 占位）→ Style → Layout → Paint → Composite。JS 阻塞解析（用 defer），CSS 阻塞渲染（关键 CSS 内联）。

盒模型与 margin（12.1）：content-box 占位=width+padding+border；border-box 占位恒=width（reset 全局设）。垂直相邻 margin 合并取 max；父子 margin 穿透用 display:flow-root 隔断；flex/grid 子项不合并。

模式识别与架构速查 ​

看到什么坏味道上什么模式
if-else / switch 长链策略（查表注册）
布尔标志位组合（loading && !error && …）状态机（互斥状态 + 显式转移）
撤销/重做需求命令（do/undo 双栈；新操作清空 redo 栈）
全局唯一（弹窗/Toast/store）单例（闭包 + 惰性创建）
重复请求 / 懒加载 / 控制访问代理（缓存 + 去重）
多渠道异构 SDK适配器（业务只认抽象）
跨模块多对多通知发布订阅（on 返回解绑函数,卸载必调）

监控上报三件套：sendBeacon（hidden 兜底 flush）+ 采样限流（防自拖垮）+ 指纹聚合（message + stack 前两帧去行列号）。上报数据必带 sessionId / release / 环境。详见 11.2。

微前端选型：多栈存量聚合 → qiankun｜重隔离（不可信代码）→ wujie/iframe｜同栈大团队共享依赖 → Module Federation（防双框架实例）｜其余 90% 需求 → 别上微前端，Monorepo + 路由懒加载。详见 11.3。

分层铁律：视图 → 业务 → 服务 → 基建，依赖只许自上而下；目录按功能域分（删除一个功能 = 删一个目录）；组件设计 = 受控/非受控双模 + 组合优于配置 + Headless 拆逻辑。详见 11.4。

Testing Library 查询优先级 ​

getByRole > getByLabelText > getByPlaceholderText > getByText
       > getByDisplayValue > getByAltText > getByTitle > getByTestId
前缀行为不匹配时
getBy*同步取一个抛错（同步断言用）
queryBy*同步取一个返回 null（断言"不存在"用）
findBy*异步等一个超时抛错（异步出现的元素用）

交互优先 userEvent 而非 fireEvent，前者模拟真实用户的聚焦/按键/失焦链。详见 9.3。

iterable  [Symbol.iterator]() → iterator { next(): {value,done}, return()? }

正则高级用法速查 ​

量词  贪婪 * + ? {m,n} ←加?变惰性→ *? +? ?? {m,n}?   贪婪先吃满再回吐,惰性满足即停
分组  (x)捕获   (?:x)只分组不存   (?<n>x)命名 → m.groups.n
引用  匹配侧 \1 数字 / \k<n> 命名;replace 侧 $1 / $<n>   引"实际匹配到的文本",成对结构靠它
断言  (?=x)右满足  (?!x)右不满足  (?<=x)左满足  (?<!x)左不满足   零宽只看不吃的"位置条件"
场景正则
千分位'12345678'.replace(/\B(?=(\d{3})+(?!\d))/g, ',') → 12,345,678
密码强度（大小写+数字、≥8 位）/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)\S{8,}$/（并列 (?=) = AND）
成对标签 / 配对引号/<(h[1-6]|b)>(.*?)<\/\1>/g、/(?<q>["']).*?\k<q>/g
取前缀后的值/(?<=\$)\d+/g 提取 $100 的 100（JS 后行断言支持变长）

贪婪遇嵌套会越界吞并（<.+> 吃到行尾最后 >），截取用惰性或排除类 [^>]+；负向先行挡不住回溯截尾（'100元'.match(/\d+(?!元)/g) 得 ['10']）；嵌套量词 (a+)+ 是 ReDoS 炸弹。详见 1.15。

RxJS 拍平操作符选型 ​

ts
import { fromEvent, debounceTime, map, switchMap, catchError, of, takeUntil } from 'rxjs';

const search$ = fromEvent<InputEvent>(input, 'input').pipe(
    debounceTime(300),
    map((e) => (e.target as HTMLInputElement).value.trim()),
    switchMap((kw) => api.search(kw).pipe(catchError(() => of([])))), // 旧请求自动取消
    takeUntil(destroy$), // 组件销毁必须收口，否则订阅泄漏
);
const sub = search$.subscribe(render);
// sub.unsubscribe() / destroy$.next() 二选一

# EP.29 二叉搜索树

> 对应正文：[22-frontend-data-structures.md](../22-frontend-data-structures.md)（22.5 二叉搜索树：有序世界的守门人）· 示例：`data-structures/examples/22-05-bst.ts`、`data-structures/examples/22-06-avl.ts`

## 剧情回顾

- **第 1 格**：像素酱发现有序数组二分查找飞快，但插入一个元素后面全体搬家——想要查找插入都快的结构。
- **第 2 格**：码叔揭秘 BST 性质：左 < 根 < 右，每比较一次就砍掉一半候选，查找插入都是树高 O(log n)。
- **第 3 格**：像素酱画出一棵小树（根 5，左右 3/7，孙辈 2/4/6/8），中序遍历点亮 2→3→4→5→6→7→8，天然升序；角落提醒：顺序插入会退化成链表，AVL 旋转救场。
- **第 4 格**：码叔结案——DOM、虚拟 DOM、级联选择、路由树都是树；顺序插入退化、删双子找中序后继、递归爆栈是三大坑。

## 知识点拆解

### 第 1 格 · 数组的两难

- 有序数组：二分查找 O(log n)，但 `splice` 插入 O(n)；
- 无序数组：尾部插入 O(1)，但查找 O(n)；
- 鱼与熊掌不可兼得？BST 说：我两个都要。

### 第 2 格 · BST 的左小右大

```ts
function insert(node: Node | null, v: number): Node {
  if (!node) return { value: v, left: null, right: null }
  if (v < node.value) node.left = insert(node.left, v)
  else node.right = insert(node.right, v)
  return node
}
```

- 不变量：**左子树所有值 < 根 < 右子树所有值**；
- 查找：与根比一次，小走左、大走右，每层淘汰一半——平衡时树高 log n；
- 插入：按查找路径走到空位，挂上新节点，O(树高)。

### 第 3 格 · 中序遍历 = 天然排序

```ts
function inOrder(node: Node | null, out: number[] = []) {
  if (!node) return out
  inOrder(node.left, out)
  out.push(node.value)
  inOrder(node.right, out)
  return out
}
```

- 左 → 根 → 右的访问顺序，配合 BST 不变量，输出必然升序；
- 反向中序（右 → 根 → 左）即得降序，范围查询也可靠它剪枝；
- **退化警告**：按 1,2,3,4,5 顺序插入，树长成一条右斜链，树高变 n，所有操作退回 O(n)——AVL/红黑树靠**旋转**维持平衡。

### 第 4 格 · 树在前端

- **DOM 树**：整棵页面结构；**虚拟 DOM diff**：两棵树按层对比打补丁；
- **级联选择器/路由树**：路径即树路径，逐段匹配；
- 删除节点三种情况：叶子直接删；单子节点子承父位；双子节点用**中序后继**（右子树最小值）顶替后再删后继。

## 坑点清单

> 🔗 正文对照：[《22.11 本章避坑清单》](../22-frontend-data-structures#_22-11-本章避坑清单)

1. 顺序插入退化成链表：树高从 log n 涨到 n，查找插入全变 O(n)——生产用 AVL/红黑树等自平衡树；
2. 删除双子节点直接摘除会断子树：必须找中序后继（或前驱）交换值后再删；
3. 深递归爆栈：树的深度大时递归遍历/插入会撑爆调用栈，改迭代 + 显式栈；
4. 只记"左小右大"到直接子节点：BST 不变量是对**整棵子树**生效，校验一棵 BST 要带上界下界递归。

## 自测 3 题（含答案）

1. **BST 查找插入为什么都是 O(log n)？**——每次比较淘汰一半候选，操作步数等于树高；平衡树的树高是 log n，所以是 O(log n)。
2. **中序遍历 BST 为什么得到升序？**——访问顺序是左→根→右，而 BST 保证左子树全小于根、右子树全大于根，递归展开后输出必然从小到大。
3. **删除有两个孩子的节点该怎么做？**——找到中序后继（右子树最小节点），用它的值覆盖待删节点，再删除那个后继（它最多只有一个孩子，转化为简单情况）。

# EP.26 栈与队列

> 对应正文：[22-frontend-data-structures.md](../22-frontend-data-structures.md)（22.2 栈与队列：LIFO 与 FIFO 的分工）· 示例：`data-structures/examples/22-01-stack.ts`、`data-structures/examples/22-02-queue.ts`

## 剧情回顾

- **第 1 格**：标签君的撤销功能用数组 `shift()` 取最旧一条记录，十万条历史一压栈，页面直接转圈——头部取元素全体搬家，O(n)。
- **第 2 格**：码叔揭秘——栈是弹夹（LIFO，尾部进出），队列是排队（FIFO，尾部进头部出）；`push/pop/peek` 全在尾部操作，都是 O(1)。
- **第 3 格**：像素酱实证括号匹配 `"([)]"`：`(` 压栈、`[` 压栈，读到 `)` 时栈顶是 `[`，不配对，立刻判负。
- **第 4 格**：码叔结案——别把数组 `shift` 当队列，高频出队换环形/双栈队列，空栈 `pop` 前先判空。

## 知识点拆解

### 第 1 格 · 数组头部操作为什么慢

- 数组是连续内存 + 下标索引，`shift()` 删掉首元素后，后面 n-1 个元素**全部前移一位**；
- 十万条历史意味着每次撤销触发十万次搬移，主线程被占满，动画掉帧、输入卡顿；
- 同理 `unshift()` 头部插入也是 O(n)，批量场景都要警惕。

### 第 2 格 · 栈与队列的 O(1) 秘诀

```ts
class ArrayStack<T> {
  private arr: T[] = []
  push(v: T) { this.arr.push(v) }      // 尾部进
  pop(): T | undefined { return this.arr.pop() }  // 尾部出
  peek(): T | undefined { return this.arr.at(-1) }
}
```

- 栈：**LIFO**（后进先出），只在一端（栈顶）进出，像弹夹压弹退弹；
- 队列：**FIFO**（先进先出），尾部进、头部出，像食堂排队打饭；
- 只碰尾部就不需要搬家，所以 `push/pop` 是 O(1)；队列出队要碰头部，得用**环形缓冲**或**双栈**（入栈 + 出栈倾倒）把均摊成本降到 O(1)。

### 第 3 格 · 有效括号走查

```ts
function isValid(s: string): boolean {
  const st: string[] = []
  const map = { ')': '(', ']': '[', '}': '{' }
  for (const ch of s) {
    if (ch in map) {
      if (st.pop() !== map[ch as keyof typeof map]) return false
    } else st.push(ch)
  }
  return st.length === 0
}
```

- 开括号压栈；闭括号弹出栈顶比对，不配立即 `false`；
- `"([)]"`：栈 `[ '(', '[' ]`，遇 `')'` 弹出的却是 `'['`——不匹配；
- 结束后栈必须为空，否则有未闭合的开括号。同类套路：十进制转二进制（余数入栈再依次弹出）。

### 第 4 格 · 前端里的栈与队列

- **栈**：函数调用栈、浏览器历史后退、编辑器撤销/重做、宏任务里的递归转迭代；
- **队列**：宏/微任务队列、消息订阅、BFS 层序遍历、请求限流排队；
- 选型口诀：要"回头路"用栈，要"先来后到"用队列，头部高频出队别用裸数组。

## 坑点清单

> 🔗 正文对照：[《22.11 本章避坑清单》](../22-frontend-data-structures#_22-11-本章避坑清单)

1. 拿数组 `shift/unshift` 当队列用：头部操作 O(n)，十万级数据直接卡死，换环形队列或双栈队列（均摊 O(1)）；
2. 空栈 `pop/peek` 返回 `undefined`，不判空就拿去比对会出隐蔽 bug；
3. 括号匹配结束忘记检查栈空：`"((("` 走完循环没报错，其实全没闭合；
4. 撤销栈不设上限：内存无限膨胀，应封顶（如 100 条）淘汰最旧记录。

## 自测 3 题（含答案）

1. **为什么数组不适合直接当队列？怎么改？**——`shift` 出队要全体前移 O(n)；改用环形缓冲（head/tail 指针绕圈）或双栈（入栈只管 push，出栈为空时把入栈整体倒过来），均摊 O(1)。
2. **用栈判断有效括号的核心步骤？**——开括号压栈；闭括号弹栈顶比对，不配即 false；遍历结束后栈必须为空，三者缺一就漏判。
3. **宏任务队列和调用栈分别是哪种结构？**——调用栈是栈（LIFO，最后调用的函数最先返回）；宏/微任务队列是队列（FIFO，先入队的任务先执行）。

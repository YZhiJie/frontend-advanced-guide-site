# EP.32 动态规划五步法

> 对应正文：[22-frontend-data-structures.md](../22-frontend-data-structures.md)（22.9 动态规划：把算过的记住）· 示例：`data-structures/examples/22-10-dp.ts`

## 剧情回顾

- **第 1 格**：标签君用递归求 `fib(50)`，浏览器直接卡死——指数级重复计算把风扇都吹起飞了。
- **第 2 格**：码叔揭秘 DP 三要素（重叠子问题 + 最优子结构 + 无后效性），以及记忆化搜索与递推 DP 两种写法。
- **第 3 格**：像素酱实证最大子数组和：`[-2,1,-3,4,-1,2,1,-5,4]` 逐格填表 `dp[i]=max(nums[i], dp[i-1]+nums[i])`，最终答案 6。
- **第 4 格**：码叔结案——五步法模板 + 状态压缩降到 `O(1)` 空间，并给出三大坑点。

## 知识点拆解

### 第 1 格 · 递归为什么会卡死

```js
function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}
```

- `fib(50)` 的调用树约有 `2^50` 个节点；
- 大量子问题（如 `fib(3)`）被重复计算了成千上万次；
- 这就是典型的**重叠子问题**，也是 DP 的入场券。

### 第 2 格 · DP 三要素与两种写法

| 要素 | 含义 |
| ---- | ---- |
| 重叠子问题 | 同一子问题被反复求解，值得缓存 |
| 最优子结构 | 大问题最优解可由子问题最优解推出 |
| 无后效性 | 子问题解决后不再受后续决策影响 |

```js
// 记忆化（自顶向下）
memo[n] ??= fib(n - 1) + fib(n - 2);

// 递推（自底向上）
dp[i] = dp[i - 1] + dp[i - 2];
```

- 记忆化：保留递归结构，加个缓存；
- 递推：从最小子问题开始填表，无递归栈。

### 第 3 格 · 最大子数组和填表

数组 `[-2,1,-3,4,-1,2,1,-5,4]`：

```js
dp[i] = max(nums[i], dp[i - 1] + nums[i]);
```

逐格填写：`-2 → 1 → -2 → 4 → 3 → 5 → 6 → 1 → 5`，最大值 6 对应子数组 `[4, -1, 2, 1]`。**前序和一旦为负，果断从当前元素重新开始。**

### 第 4 格 · 五步法模板

1. **定义状态**：`dp[i]` 表示什么；
2. **转移方程**：`dp[i]` 与 `dp[i-1]` 的关系；
3. **初始化**：`dp[0]`、边界值；
4. **遍历顺序**：正序、倒序还是斜着来；
5. **返回值**：`dp[n-1]` 还是 `max(dp)`。

状态压缩：若 `dp[i]` 只依赖前 1~2 项，可用滚动变量把空间从 `O(n)` 降到 `O(1)`。

## 坑点清单

> 🔗 正文对照：[《22.11 本章避坑清单》](../22-frontend-data-structures#_22-11-本章避坑清单)

1. **`dp[0]` 初始化漏掉**：忘记给边界赋初值，后面全靠 `undefined` 推导；
2. **遍历方向写反**：正着推的题倒着写，状态还没算出来就被引用；
3. **不满足无后效性别硬套**：如「带障碍物的最短路径」若障碍物会变化，就不能用简单 DP；
4. **把记忆化当 DP**：记忆化只是 DP 的递归版，理解状态转移才是核心。

## 自测 3 题（含答案）

1. **递归求 `fib(50)` 为什么卡死？**——调用树指数膨胀（约 `2^50`），大量子问题被重复计算；用记忆化或递推 DP 可降到 `O(n)`。
2. **最大子数组和的状态转移方程是什么？**——`dp[i] = max(nums[i], dp[i-1] + nums[i])`，即「独自开张」或「接在前一段后面」取大者；答案为 `max(dp)`。
3. **动态规划的五步法是哪五步？**——定义状态、转移方程、初始化、遍历顺序、返回值；若状态只依赖前有限项，可用滚动数组压缩空间到 `O(1)`。

# 漫画剧场风格规范 · 霓虹墨 Neon Ink v1.0

> 本规范是 `comics/` 全部漫画的唯一视觉与叙事标准。新增或修改任何一话，都必须对照本文档执行。
> 校验入口：`node comics/check-comics.mjs`（manifest 一致性 + SVG 良构性 + 文本溢出启发式 + MD 完整性）。

## 1. 画布与分格

| 项 | 规定 |
| ---- | ---- |
| 画布 | `viewBox="0 0 1200 840"`，深墨底渐变（左上 `#0b1220` → 右下 `#101a33`） |
| 分格 | 2×2 四格，面板尺寸 **572×361**，圆角 14 |
| 面板坐标 | 左上 `(20,84)`、右上 `(608,84)`、左下 `(20,462)`、右下 `(608,462)` |
| 页眉 | EP 徽章（`#7C3AED` 圆角矩形 92×36）+ 标题（渐变字 26px）+ 右侧系列名；页眉下 1160×2 渐变分隔线（y=62） |
| 装饰 | 每格 1~2 条斜切光楔（多边形，霓虹色 opacity ≤0.05），禁止高不透明度大色块 |

## 2. 色板（60/30/10）

| 用途 | 色值 |
| ---- | ---- |
| 底色（60%） | `#0b1220` `#101a33` `#0e1730`（面板） |
| 结构线/弱文本（30%） | `#1e2a44` `#223055` `#64748b` `#94a3b8` `#e2e8f0` |
| 霓虹强调（10%） | 青 `#22d3ee` / 紫 `#7C3AED` `#a78bfa` / 品红 `#f472b6` / 橙 `#f97316` / 绿 `#34d399` / 黄 `#fbbf24` |
| 面板编号色 | 1=青、2=紫、3=品红、4=橙 |

对比度规则：气泡为浅底（`#f8fafc`）配深字（`#0b1220`）；深底上正文用 `#e2e8f0`；强调词单独 `<tspan>` 换霓虹色。所有文字对比度 ≥ 4.5:1。

## 3. 字号阶梯与字体

| 元素 | 字号 | 字色 |
| ---- | ---- | ---- |
| 话标题 | 26 bold | 渐变（青→紫） |
| 面板标题 | 17 bold | `#e2e8f0` |
| 气泡正文 | 15~16 | `#0b1220`（浅底） |
| 代码 | 12~13 mono | `#7dd3fc` / `#fbbf24` / `#34d399` |
| 注脚/水印 | 11~12 | `#64748b` |

- `font-family="'PingFang SC','Hiragino Sans GB','Microsoft YaHei',sans-serif"`；代码用 `'SF Mono','JetBrains Mono',Consolas,monospace`。
- **每个 `<text>`/`<tspan>` 必须显式写 `font-size`**（校验脚本依赖）。
- 气泡单行 ≤ 17 个汉字（约 272px），代码单行 ≤ 40 字符；预计行宽 = 汉字数×字号 + ASCII 数×0.58×字号，校验器按此做溢出启发式。

## 4. 组件规范

- **气泡**：圆角 10 浅底矩形 + 小三角尾巴指向说话人；尾巴必须连到头像。
- **头像（半身 44px 级）**：头圆 r≈17 + 发型 + 眼睛两点 + 微笑弧 + 身体圆角矩形。见 `samples/character-sheet.svg`。
- **代码芯片**：深底 `#0a0f1c`、描边霓虹色（opacity 0.35）、圆角 8、内边距 ≥12。
- **坑点标签**：橙 `#f97316` 小圆角条 + "⚠ 坑点" 前缀，只出现在第 4 格。
- **转义**：文本中 `<` → `&lt;`、`>` → `&gt;`、`&` → `&amp;`；禁止在属性值里出现 `>`。

## 5. 三角色设定（v2 定妆稿）

| 角色 | 人设 | 视觉锚点 |
| ---- | ---- | ---- |
| 像素酱 | 提问担当，好奇心强、一针见血 | 青色高马尾 + 紫色卫衣 + 胸前 `{}` 徽章 |
| 标签君 | 行动派，热情外向、爱动手 | 橙色刺猬头 + 蓝外套 + HTML5 盾徽 |
| 码叔 | 教授，沉稳专业、负责总结 | 白发白须 + 圆框眼镜 + 浅灰大褂 + 指教鞭 |

叙事分工：像素酱/标签君负责"提出问题、制造冲突"，码叔负责"揭示原理、给出最佳实践"。每话至少两角色出场。

## 6. 叙事结构（四幕）

1. **第一格 · 困境**：真实开发场景抛出问题（页面卡了/报错了/被质疑了）；
2. **第二格 · 揭秘**：原理拆解，配 1 段迷你代码芯片；
3. **第三格 · 实证**：经典示例或对比（正确 vs 错误 / 执行顺序图示）；
4. **第四格 · 结案**：最佳实践 + ⚠ 坑点标签 + 一句码叔总结。

每格左上角有编号色块（1~4）+ 4~8 字面板标题；整话无对白超过 3 行/气泡。

## 7. 命名与文件

- 一话 = `EP.NN-slug.svg` + `EP.NN-slug.md`，NN 两位数，slug 全小写连字符；
- 一话严格对应正文一个部分（`01-javascript-advanced.md` … `18-worker-messaging.md`）；
- 新增话必须同步：`manifest.json`、`README.md` 导航表、（如涉及）`check-comics.mjs` 白名单；
- 讲解 MD 结构固定：`# EP.NN 标题` → `> 对应正文` → `剧情回顾` → `知识点拆解（四格各一节）` → `坑点清单` → `自测 3 题（含答案）`，并链接到正文章节与 examples 示例。

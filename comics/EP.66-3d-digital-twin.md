# EP.66 3D 场景里的孪生兄弟

> 对应正文：[92-3d-digital-twin.md](../92-3d-digital-twin.md)（92.1 场景图 / 92.2 射线拾取 / 92.4 数字孪生）· 示例：`examples/92-01-3d-digital-twin.ts`

## 剧情回顾

- **第 1 格**：3D 场景点击设备没反应——3D 物体不是 DOM，没有 onclick。
- **第 2 格**：码叔揭秘射线拾取——从相机发射射线，命中哪个物体就是点中了谁。
- **第 3 格**：像素酱实证数字孪生数据绑定——传感器数据驱动 Mesh 的颜色/高度/透明度。
- **第 4 格**：码叔结案——GIS 坐标转换 + InstancedMesh 降 Draw Call。

## 知识点拆解

### 第 1 格 · 3D 交互的特殊性

- 3D 物体渲染在 Canvas 上，不是 DOM 元素；
- 没有原生点击事件，需要自己实现拾取；
- 核心工具：`THREE.Raycaster`。

### 第 2 格 · 射线拾取（Raycaster）

```
鼠标屏幕坐标 → NDC(-1~1) → setFromCamera → intersectObjects
```

- 从相机位置沿鼠标方向发射射线；
- 与场景物体的包围盒/三角面求交；
- 返回按距离排序的命中列表，`hits[0]` 就是点中的物体。

### 第 3 格 · 数字孪生数据绑定

- 建立"设备 ID → Mesh"映射；
- WebSocket 推送实时数据，更新 Mesh 属性：
  - 温度 → 材质颜色（冷蓝→热红）
  - 功率 → 高度（scale.y）
  - 状态 → 透明度（在线/离线/告警）

### 第 4 格 · GIS 坐标与性能

- 经纬度转局部坐标：1°纬度≈111km，经度×cos(lat)；
- InstancedMesh：N 个相同物体 1 次 Draw Call；
- LOD：远距低模、近距高模；
- 切换场景时 dispose 几何体和材质防内存泄漏。

## 坑点清单

> 🔗 正文对照：[《92.7 本章避坑清单》](../92-3d-digital-twin#_92-7-本章避坑清单)

1. 点击不准 → 用 NDC 坐标转换，注意递归参数；
2. 模型全黑 → 没加光照，MeshStandardMaterial 需要光源；
3. 内存泄漏 → 移除物体时 dispose 几何体/材质/纹理。

## 自测 3 题（含答案）

1. 3D 场景点击物体的核心原理是什么？——**射线拾取：从相机发射射线与物体求交**。
2. 数字孪生如何让 3D 模型"活"起来？——**建立设备 ID→Mesh 映射，实时数据更新 Mesh 属性（颜色/高度/透明度）**。
3. 经纬度转场景坐标时，经度为什么要乘 cos(lat)？——**因为经线在高纬度收敛，1°经度的实际距离随纬度增大而缩短**。

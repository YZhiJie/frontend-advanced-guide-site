盒模型与外边距合并 · 可观测实验

对应 12.1 的 CSS 地基：width 到底算到哪、为什么子元素的 margin 会"穿"到父元素外面。每个实验都给出实测像素值与修复开关。

实验 1：content-box vs border-box（怪异盒模型）

content-box：width:200 只含内容区
border-box：width:200 含 padding+border
点击下方按钮测量…

结论：同样 width:200px; padding:20px; border:10px，标准盒实际占 260px（width 只算内容区），怪异盒恒为 200px（width 含 padding+border，内容区被压缩到 140px）。组件库与 reset 全局设 box-sizing: border-box，栅格 width:50% + padding 才不会溢出换行。

实验 2：父子 margin-top 穿透（最常见的外边距合并）

下方卡片里蓝色父元素没有 border / padding / BFC，首子元素带 margin-top:40px（说明文字放在卡片外，保证几何测量干净）：

子元素 margin-top:40px —— 看，40px 穿到了父元素外面！
点击按钮测量…

结论：父元素没有 border-top / padding-top、也没有建立 BFC 时，首子元素的 margin-top 会"穿透"与父元素合并。三种修法都在父元素上做文章：display: flow-root（无副作用，首选）、任意 1px border/padding 隔断、overflow: hidden 建立 BFC（会裁切溢出内容，慎用）。

实验 3：相邻兄弟外边距合并（取较大值，不是相加）

上一个兄弟：margin-bottom:30px
下一个兄弟：margin-top:20px
flex 容器内：margin-bottom:30px
flex 项：margin-top:20px（不合并，间距 50px）
点击按钮测量…

结论：普通块级兄弟的上下 margin 合并，间距 = max(30, 20) = 30px 而非 50px；flex / grid 容器的子项是弹性/网格项，不发生外边距合并（实测 50px）——这也是现代布局中间距行为更符合直觉的原因之一。空块自身的上下 margin 还会自我合并，规则同源。

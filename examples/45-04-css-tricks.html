CSS 实用技巧实验台：锚点定位、作用域、自适应输入与打印

这个页面不依赖任何框架，直接双击打开即可。把窗口调窄可以观察容器行为； 用“打印预览”观察最后一张卡片的断页与链接展开效果。

1. Anchor Positioning

悬停或聚焦按钮：浮层通过 anchor-name / position-anchor 自动对齐，不再依赖 JS 计算坐标；不支持时由 @supports 降级为普通绝对定位。

复制邀请链接发给同事

2. @scope 与 light-dark()

同一个 .badge 只要放进卡片内部就自动变成品牌色胶囊，外部样式不受影响； 主题色由 light-dark() 跟随系统深浅色。

组件内 badge

卡片边框颜色由 :scope 基于品牌色混合得到。

外部 badge 不受影响

3. field-sizing: content

输入多行文字，textarea 自动长高到上限，不需要 JS 监听 input 再改 height。

4. hidden="until-found"

隐藏内容仍可被浏览器“页内查找”命中；命中前触发 beforematch， 适合折叠的帮助说明与 FAQ。

这段文字默认不可见。用 Ctrl/Cmd + F 搜索“前庭敏感”会触发 beforematch， 浏览器会自动把它展开并滚动到匹配位置。

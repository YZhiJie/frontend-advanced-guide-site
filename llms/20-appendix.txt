## 附录 A：学习路线与自查清单

### 建议节奏（约 12 周）

| 阶段 | 内容 | 自查标准 |
| ---- | ---- | -------- |
| 第 1~2 周 | 第一部分 JS 高级特性 | 能手写防抖/深拷贝/并发池；能讲清事件循环输出题 |
| 第 3~4 周 | 第二部分 TypeScript | 能手写 Partial/Pick/ReturnType；会用 infer 做路径类型 |
| 第 5 周 | 第三部分 工程化 | 独立配置 Vite 项目；能分析并优化首包体积 |
| 第 6~7 周 | 第四部分 框架深入 | 能讲清 Fiber/响应式原理；能定位一次卡顿的渲染原因 |
| 第 8 周 | 第五、六部分 状态与网络 | 独立封装请求层（401 续期 + 竞态防护） |
| 第 9 周 | 第七部分 安全 + 第九部分 测试 | 通过 XSS/CSRF 清单自查；核心模块有单测 |
| 第 10 周 | 第十部分 浏览器原理 | 能用 Performance 面板定位并修复一个真实卡顿 |
| 第 11~12 周 | 第八、十一部分 + 实战 | 完成一次小型全链路实践（如带监控的组件库/工具站） |

### 面试高频自查清单

- [ ] 事件循环：宏/微任务、`await` 的本质、Node 与浏览器差异
- [ ] 闭包与内存：循环陷阱、四种内存泄漏、WeakMap 的适用场景
- [ ] 原型与继承：手写 instanceof、寄生组合继承、`new` 的过程
- [ ] Promise：手写 then 链、all/race/any 区别、并发池
- [ ] TypeScript：泛型约束、条件类型、infer、手写工具类型、`satisfies`
- [ ] React：Fiber 与两阶段渲染、Hooks 顺序机制、memo 组合拳、并发特性、React 19 变化
- [ ] Vue：Proxy 响应式、依赖收集/派发、computed vs watch、shallowRef 场景
- [ ] 工程化：Vite 快的原因、Tree Shaking 前提、缓存黄金法则、monorepo 工作流
- [ ] 网络：HTTP/2 vs 1.1、强/协商缓存流程、CORS 预检、竞态处理、断点续传
- [ ] 安全：XSS 三类与防御、CSRF 三层防御、CSP、原型污染
- [ ] 浏览器：重排重绘合成、Layout Thrashing、虚拟列表、Web Worker
- [ ] 软素质：一次性能优化经历（指标基线 → 定位 → 手段 → 结果）
